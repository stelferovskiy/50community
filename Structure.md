# Путеводитель по архитектуре и коду сайта [.50] COMMUNITY

Файл `index.html` представляет собой автономное одностраничное веб-приложение (**Single Page Application / SPA**). Весь проект объемом более 1500 строк кода разделен на три логических слоя:
1. **Служебная часть и стилизация** (`<head>`, Tailwind CSS, кастомные стили);
2. **Визуальная разметка** (`<header>`, экраны `<main>`, модальные окна, подвал);
3. **Программная логика JavaScript** (состояние приложения, движок карт, авторизация, аудио-синтезатор и синхронизация).

Ниже подробно расписано, за что отвечает каждый конкретный модуль.

---

## ЧАСТЬ 1. Служебная шапка (`<head>`)

* **Подключение библиотек через CDN:**
  * `tailwindcss.com` — основной CSS-фреймворк для быстрой адаптивной верстки.
  * `font-awesome` — тактические векторные иконки (шевроны, оружие, сейфы, замки, Discord).
  * `fonts.googleapis.com` — шрифты **Chakra Petch** (тактический HUD/рубленый шрифт) и **Inter** (читаемый текст интерфейса).
  * `@supabase/supabase-js` — облачный клиент для прямого подключения к базе данных PostgreSQL.

* **Конфигурация Tailwind (`tailwind.config`):**
  * Задает уникальную цветовую палитру отряда `tactical`: `tactical-black` (`#090a0d`), `tactical-card` (`#141722`), акцентные красные оттенки (`#e50914`, `#ff1e27`), золотой (`#f59e0b`) и серый.

* **Кастомный блок `<style>`:**
  * Фоновый тактический градиент со слабой сеткой и круговым красным свечением.
  * Стилизованный красный скроллбар (`::-webkit-scrollbar`).
  * Классы неонового свечения (`glow-red`, `glow-gold`, `text-glow-red`).
  * Специфические стили для интерактивной карты (изменение курсора на «руку-захват» при перетаскивании).

## ЧАСТЬ 2. Верхняя навигация и мобильное меню (`<header>`)

* **Блок логотипа (`group`, `onclick="navigateTo('home')"`):**
  * Пытается загрузить файл `logo.png` (или `logo.jpg`).
  * Если файл не найден, срабатывает обработчик `onerror`, который плавно переключает отображение на детализированную векторную SVG-эмблему (шлем спецназа с визором, патроны .50 BMG и шеврон `[.50] COMMUNITY`).
  * При клике возвращает пользователя на главную страницу.

* **Кнопки десктопного меню:**
  * `nav-btn-maps` — переход к интерактивным картам;
  * `nav-btn-rules` — переход к регламенту;
  * `nav-btn-members` — переход к личному составу (с бейджем счетчика бойцов);
  * `#nav-auth-container` — динамическая кнопка: если боец не вошел — показывает «Вход / Регистрация», если авторизован — отображает позывной и статус;
  * Ссылка на сервер Discord сообщества (`https://discord.com/invite/50community`).

* **Мобильная панель (`#mobile-menu`):**
  * Выдвижная шторка для смартфонов и планшетов, дублирующая все кнопки шапки в вертикальном формате.

## ЧАСТЬ 3. Основные страницы и экраны (`<main>`)

В приложении используется переключение вкладок без перезагрузки: активная вкладка имеет класс `block`, скрытые — `hidden`.

### 1. Главная страница (`#tab-home`)
* **Hero-баннер (верхний блок):**
  * Заголовок с неоновым свечением, главный лозунг дивизиона.
  * Индикатор статуса набора (пульсирующая зеленая/красная точка с текстом).
  * Карточка официальной эмблемы отряда.
* **Сетка 5 карточек ролей (`#home-role-stats-grid`):**
  * Генерируется скриптом `renderHomeRoleStats()`.
  * 1-я карточка — «Весь состав» (ведет на общий список участников).
  * 2–5 карточки — ключевые статусы отряда по убыванию приоритета (Priority #2, Ранг 3, Ранг 4, Ранг 5).
* **Блок философии и преимуществ:**
  * 4 карточки («Чистая голосовая связь», «Пул ключей и комнат», «Страховка соклановцев», «Внутренние ивенты»).
* **Сводка новостей Discord (`#home-news-container`):**
  * Компактный контейнер с ограничением высоты и плавным скроллом.
  * Отображает сообщения из Discord-канала (автор, аватарка, время, текст).
  * Кнопка принудительного обновления сообщений через шлюз.

### 2. Официальный регламент (`#tab-rules`)
* Дословный текст устава подразделения:
  * **Блок 1:** Порядок вступления в клан (роли `.50` и `100м`), требования к стилю игры (запрет кемперства), поручительство двух бойцов `1000м`, 24 часа на согласование.
  * **Блок 2:** Таблица иерархии ролей (`100м + .50`, `500м`, `1000м`, `STAFF`) с критериями и процедурой присвоения.
  * **Блок 3:** Дисциплинарная политика, жесткое правило 3 варнов (исключение без восстановления) и перечень нарушений.
* Кнопка для открытия оригинального Google-документа.

### 3. Интерактивные карты (`#tab-maps`)
* **Панель переключения карт:** Ферма (Farm), Долина (Valley), Оружейная (Armory), Нортридж (Northridge).
* **Фильтры меток:** раздельное включение/выключение выходов ЧВК, точек респавна, сейфов/лута, боссов и закрытых дверей с ключами.
* **Вьюпорт карты (`#map-viewport`):**
  * SVG-слой ландшафта (`#map-svg-terrain`), рисующий дороги, реки, ключевые постройки (Мотель, Зернохранилище, Бункер, Вилла, Отель).
  * Слой интерактивных меток (`#map-markers-layer`), поддерживающий масштабирование колесиком мыши, перетаскивание курсором или пальцем на сенсорном экране.
* **Боковая панель разведданных (`#intel-card`):**
  * При клике на любую метку показывает название, уровень опасности, нужный ключ, условия эвакуации и кнопку копирования тактических координат в буфер обмена.

### 4. Реестр личного состава (`#tab-members`)
* **Панель управления поиском и фильтрацией:**
  * Поле живого поиска по позывному или Discord тегу;
  * Сортировка: по иерархии ролей (старшие ранги первыми), по статусу в сети (Online / В рейде), по алфавиту, по дате вступления;
  * Фильтр-кнопки по каждой из 5 отслеживаемых ролей Discord.
* **Карточки оперативников (`#members-grid-container`):**
  * Аватарка бойца, позывной, бейджи ролей;
  * Золотое свечение для высшего ранга (`Priority 1`) и красное свечение для `Priority 2`;
  * Кнопка быстрого копирования Discord ID бойца.

### 5. Панель управления / Админка (`#tab-admin`)
* **Шлюз авторизации (`#admin-locked-view`):**
  * Закрытый вход с вводом пароля (по умолчанию `admin123`).
* **Рабочее пространство администратора (`#admin-unlocked-view`):**
  * **Вкладка 1 (Главные данные):** редактирование названия сообщества, тега, Discord-ссылки, лозунга и статуса набора.
  * **Вкладка 2 (Интеграция Discord):** настройка Guild ID, Channel ID, роли по умолчанию, привязка URL Cloudflare Worker и настройка 5 ролей иерархии.
  * **Вкладка 3 (Метки на картах):** таблица всех пользовательских и стандартных меток с возможностью удаления.
  * **Вкладка 4 (База Данных SQL):** интерактивная консоль выполнения SQL-запросов (`SELECT`, `INSERT`), таблица пользователей `public.users` и модальное окно подключения к Supabase PostgreSQL.

## ЧАСТЬ 4. Модальные окна и всплывающие уведомления

1. **Окно входа и регистрации (`#auth-modal`):**
   * Вкладка входа по позывному/email и паролю;
   * Вкладка регистрации нового бойца с автоматической генерацией жетона в SQL-базе;
   * Кнопки быстрой подстановки демо-аккаунтов для тестирования.
2. **Личное дело бойца (`#profile-modal`):**
   * Карточка текущего профиля с позывным, почтой, ролью и кнопкой выхода из сессии («Сдать жетон»).
3. **Настройки Supabase (`#supabase-modal`):**
   * Подключение внешнего бесплатного облака PostgreSQL через Project URL и Anon API Key.
4. **Тактические тосты (`#toast-container`):**
   * Всплывающие уведомления в правом нижнем углу экрана (зеленые — успех, красные — ошибка, серые — системная информация).

## ЧАСТЬ 5. Программная логика (Блок `<script>`)

* **`DEFAULT_COMMUNITY_DATA` и структуры данных:**
  * Хранят базовую конфигурацию портала, предустановленные метки карт, список участников и сообщения на случай первого запуска или сброса настроек.
* **`AudioEngine` (Звуковой синтезатор Web Audio API):**
  * Генерирует тактические звуки клика и радиосигнала программно через звуковые волны браузера (`createOscillator`). Не требует загрузки внешних `.mp3` файлов и работает автономно.
* **Маршрутизация (`navigateTo`, `switchTab`, `checkRouteFromUrl`):**
  * Отслеживает хэш в URL (`#maps`, `#rules`, `#members`, `#admin`), переключает экраны и подсвечивает активные кнопки шапки.
* **Движок карты:**
  * `selectMap(mapKey)` — смена локации и перерисовка SVG-схемы;
  * `updateMapTransform()`, `zoomMap()`, `startMapDrag()` — расчет координат, перемещение полотна и масштабирование;
  * `toggleMapFilter()` — фильтрация отображаемых точек.
* **Синхронизация Discord (`syncDiscordLiveFeed()`):**
  * Выполняет безопасный сетевой запрос к Cloudflare Worker прокси, забирая актуальное число участников с ролью, список пользователей и последние посты из канала.
* **Система сортировки бойцов:**
  * `getMemberRoleWeight()` — вычисляет числовой приоритет бойца на основе привязанных ролей от `Priority 1` (высший) до младших званий.
* **SQL и система безопасности:**
  * `hashPassword()` — хэширование паролей пользователей с использованием криптографического стандарта браузера **SHA-256** (`crypto.subtle`).
  * `saveDataToLocalStorage()` — надежное сохранение состояния портала в памяти браузера.
